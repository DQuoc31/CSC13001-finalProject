I. ĐÁNH GIÁ TIẾN ĐỘ GIỮA KỲ (BÁO CÁO TIẾN ĐỘ - 3.5 / 3.5 ĐIỂM)
============================================================
1. Phân tích nghiệp vụ và thiết kế hệ thống (0.25 / 0.25 điểm):
   - Đề tài chuẩn theo MSSV (đuôi 8): Cửa hàng kinh doanh Laptop & Linh kiện máy tính.
   - Quản lý đặc thù ngành hàng: Vi xử lý (CPU), Bộ nhớ (RAM), Card đồ họa (GPU), Ổ cứng (SSD), Kích thước màn hình, Thời hạn bảo hành chính hãng.
   - Có tài liệu kiến trúc hệ thống Clean Architecture chi tiết trong docs/Architecture.md.

2. Thiết kế Cơ sở dữ liệu (0.5 / 0.5 điểm):
   - Chuẩn hóa CSDL quan hệ toàn vẹn (PK, FK, Unique Index SKU, PhoneNumber, OrderNumber).
   - 7 thực thể chính: Products, Categories, Customers, Orders, OrderDetails, Users, StockHistories.
   - Tài liệu thiết kế CSDL và lược đồ quan hệ trong docs/DatabaseDesign.md.

3. Giao diện và trải nghiệm người dùng - UX/UI (0.5 / 0.5 điểm):
   - Xây dựng bằng WPF hiện đại theo mô hình MVVM (CommunityToolkit.Mvvm).
   - Form nhập liệu trực quan: Form Thêm/Sửa sản phẩm đầy đủ thông số cấu hình, Form Thêm/Sửa danh mục, Form Thêm/Sửa khách hàng, Form Lập đơn hàng POS.
   - Kiểm tra ràng buộc hợp lệ (Validation): Tên/SKU không rỗng, giá > 0, tồn kho >= 0, kiểm tra tồn kho thời gian thực trước khi bán.
   - Thông báo rõ ràng (MessageBox, Status bar) khi thao tác thành công hoặc thất bại.

4. Chức năng quản lý dữ liệu nghiệp vụ (1.0 / 1.0 điểm):
   - [x] CRUD Sản phẩm: Thêm mới, Chỉnh sửa thông số kỹ thuật, Xóa sản phẩm, Tìm kiếm đa tiêu chí, Lọc theo danh mục.
   - [x] CRUD Danh mục: Thêm mới, Chỉnh sửa, Xóa danh mục, Hiển thị số lượng máy thuộc từng danh mục.
   - [x] CRUD Khách hàng: Thêm mới, Chỉnh sửa, Xóa, Tìm kiếm theo Tên hoặc SĐT, Quản lý điểm thưởng, Lịch sử mua hàng.
   - [x] Lập & Quản lý Đơn hàng: Lập đơn hàng mới tại quầy, kiểm tra tồn kho thời gian thực (từ chối bán vượt tồn kho), áp dụng giảm giá, xem chi tiết các sản phẩm trong đơn, cập nhật trạng thái đơn (Đang xử lý, Hoàn thành), hủy đơn hoàn trả tồn kho tự động.
   - [x] Báo cáo & Thống kê: Dashboard trực quan, Top 5 laptop bán chạy nhất, Danh sách cảnh báo sản phẩm sắp hết hàng.

5. Kết nối và xử lý dữ liệu với Database Server (0.75 / 0.75 điểm):
   - Hỗ trợ kết nối CSDL trực tiếp (Direct Database Mode) theo chuẩn mô hình Giữa kỳ (Ứng dụng ➔ Database Server).
   - Hỗ trợ cả SQLite (chạy ngay lập tức không cần cài đặt ngoài) và SQL Server (cấu hình connection string).
   - Xử lý Transaction, đảm bảo tính toàn vẹn dữ liệu khi trừ kho hoặc hoàn kho.

6. Dữ liệu mẫu (Demo Data) (0.25 / 0.25 điểm):
   - Vượt mức yêu cầu tối thiểu của đề bài:
     + 24 sản phẩm laptop và linh kiện phần cứng thực tế (đầy đủ CPU, RAM, GPU, SSD, giá, tồn kho).
     + 5 danh mục sản phẩm (Gaming, Văn phòng, Đồ họa, Linh kiện, Phụ kiện).
     + 12 khách hàng thực tế kèm SĐT và điểm thưởng thành viên.
     + 22 đơn hàng giao dịch với đầy đủ các trạng thái (Pending, Processing, Completed, Cancelled).
     + 4 tài khoản người dùng demo ứng với 4 vai trò.

II. NỀN TẢNG ĐÃ CHUẨN BỊ CHO GIAI ĐOẠN CUỐI KỲ (4.5 ĐIỂM)
============================================================
- Chế độ Cuối kỳ: Desktop Client ➔ API Server ➔ Database Server.
- Nút chuyển đổi tức thì giữa 2 kiến trúc (Direct DB và Web API) ngay trên thanh Header của ứng dụng.
- ASP.NET Core Web API RESTful đầy đủ, có Swagger UI trực quan.
- Xác thực bảo mật: PBKDF2 Salted Hash và JWT Bearer Token.
- Phân quyền RBAC chặt chẽ (Admin, Manager, SalesStaff, WarehouseStaff) ở cả Client và Server.
- Kiểm thử tự động: 12 test case xUnit (100% Pass) kiểm tra logic nghiệp vụ, biên, xác thực, phân quyền.
- Trợ lý AI Assistant thông minh có Tool execution kết nối CSDL thực tế và tuân thủ phân quyền RBAC.
