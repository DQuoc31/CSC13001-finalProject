============================================================
1. YÊU CẦU MÔI TRƯỜNG
============================================================
- Hệ điều hành: Windows 10/11
- .NET SDK: Version 8.0 hoặc 9.0 (Kiểm tra bằng lệnh: dotnet --version)
- CSDL: Hệ thống mặc định cấu hình SQLite tự động tạo và seed data vào file 'laptopstore.db' ngay khi chạy lần đầu, không cần cài đặt thêm phần mềm quản trị CSDL ngoài.
(Nếu muốn kết nối Microsoft SQL Server: Cập nhật "DatabaseProvider": "SqlServer" và ConnectionString trong appsettings.json).

============================================================
2. BIÊN DỊCH TOÀN BỘ MÃ NGUỒN VÀ CHẠY TEST
============================================================
Mở terminal tại thư mục gốc của repository:

1. Biên dịch:
   dotnet build LaptopStore.sln

2. Chạy 12 bài kiểm thử tự động (Unit Tests):
   dotnet test

============================================================
3. KHỞI CHẠY HỆ THỐNG THEO 2 MÔ HÌNH KIẾN TRÚC
============================================================
CÁCH 1: KHỞI CHẠY CHẾ ĐỘ GIỮA KỲ (Ứng dụng ➔ Database Server)
(Chạy trực tiếp Desktop Client, kết nối trực tiếp SQLite DB, không cần chạy Web API)

   cd src/LaptopStore.Client
   dotnet run

- Ứng dụng sẽ tự động khởi tạo database SQLite và nạp toàn bộ 24 sản phẩm, 5 danh mục, 12 khách hàng, 22 đơn hàng mẫu.
- Trên thanh Header hiển thị: "⚡ Chế độ Giữa kỳ: Direct Database (Ứng dụng ➔ Database Server)".

---

CÁCH 2: KHỞI CHẠY CHẾ ĐỘ CUỐI KỲ (Ứng dụng ➔ API Server ➔ Database Server)
(Gồm 2 terminal: Terminal 1 chạy Web API, Terminal 2 chạy Client)

- Terminal 1 (Khởi động API Server):
   cd src/LaptopStore.Api
   dotnet run
   (Truy cập Swagger kiểm thử API tại: http://localhost:5000/swagger)

- Terminal 2 (Khởi động Desktop Client):
   cd src/LaptopStore.Client
   dotnet run

- Bấm nút "🔄 Kiến Trúc" trên thanh Header để chuyển sang chế độ API Server.
